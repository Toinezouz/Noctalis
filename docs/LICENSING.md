# Choix de licence

## La licence retenue

**AGPL-3.0-or-later** — GNU Affero General Public License, version 3 ou
ultérieure. Le texte complet est dans [`LICENSE`](../LICENSE).

## Pourquoi celle-là

NOCTALIS est un jeu **joué à travers un réseau**. C'est exactement la
situation que l'AGPL vise, et qui distingue cette licence de la GPL ordinaire.

Avec une GPL classique, quelqu'un peut prendre ce code, le modifier, l'héberger
en ligne, et n'avoir rien à partager : il ne *distribue* pas le logiciel, il en
donne l'accès. La section 13 de l'AGPL ferme cette porte — si vous faites
tourner une version modifiée pour d'autres, vous devez proposer les sources
correspondantes aux personnes qui s'en servent.

Les conséquences concrètes, pour ce projet :

- toute amélioration déployée publiquement revient à la communauté ;
- personne ne peut transformer NOCTALIS en service fermé ou payant ;
- l'esprit du projet — gratuit, sans compte, sans publicité, soutenu
  uniquement par GitHub Sponsors — est protégé par la licence elle-même, pas
  seulement par une promesse.

## Ce que ça change pour vous

| Vous voulez… | C'est permis ? |
| --- | --- |
| Jouer | Oui, librement. |
| Lire, copier, étudier le code | Oui. |
| L'héberger pour vos amis, tel quel | Oui. |
| Le modifier pour votre usage privé | Oui, sans obligation de publier. |
| Héberger une version modifiée pour d'autres | Oui, en publiant vos modifications sous AGPL. |
| L'intégrer à un logiciel propriétaire | Non. |

## Contributions

En contribuant, vous acceptez que votre travail soit publié sous la même
licence. Le projet ne demande pas de cession de droits (pas de CLA) : vous
gardez la paternité de vos contributions.

## Assets et dépendances

Les assets originaux du projet suivent la licence du projet. Les polices
Fredoka et Nunito sont sous SIL Open Font License 1.1, compatible. Le détail
figure dans [`ASSETS.md`](ASSETS.md).

## Provenance du code

NOCTALIS reprend l'architecture technique d'un projet personnel antérieur du
même auteur (moteur de règles, serveur autoritaire, séparation public/privé,
design system). Cette reprise est faite avec l'accord de son auteur, qui est
la même personne. L'identité, les textes, les assets et le vocabulaire du jeu
sont, eux, entièrement originaux et créés pour ce projet.
